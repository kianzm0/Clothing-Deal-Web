# Account lifecycle

Migrate before deployment. Configure NEXTAUTH_URL as the canonical HTTPS public origin, ACCOUNT_MAIL_ENDPOINT as a trusted HTTPS transactional email adapter, and ACCOUNT_MAIL_SECRET as its bearer secret. The adapter accepts {to, subject, text}, delivers the email and returns 2xx when accepted. Redirects are rejected and delivery has a 10-second timeout. Unconfigured email returns 503; configure and test delivery before advertising password recovery. No email is sent by CI.

Account settings exposes verification, streaming NDJSON export, learning reset, sign-out-all and permanent deletion. Destructive actions require the current password; deletion additionally requires DELETE. Password reset and sign-out-all increment a database session version checked on every session resolution. Deleted accounts and unavailable revocation checks fail closed. Existing versionless sessions are version zero. Verification is optional and never grants an editorial role.

Tokens are 256 random bits, only SHA-256 hashes are stored, reset links expire after 30 minutes and verification links after 24 hours. Consumption is atomic and single use. Requests are serialized per account and purpose with a 60-second cooldown. Public responses do not disclose account existence; delivery failures log only a generic message. Tokens travel in URL fragments, not server access logs. Configure infrastructure request throttling as a separate production protection.

The authenticated daily account-retention job deletes expired tokens and interaction history older than 180 days for up to 100 accounts per invocation. It also resets their learned weights so removed history does not survive in model parameters. Monitor mayHaveMore and invoke additional bounded batches until the backlog is empty; physical retention depends on healthy cleanup. Explicit learning reset deletes all interactions and weights immediately; preferences and watchlist stay. Training and reset lock the same account. Account deletion cascades related data. Backups and infrastructure logs require operator retention/deletion policies.

Exports fetch 200 rows at a time and stream with backpressure; no password hashes or recovery tokens are exported. Rows created after export starts are excluded; this is a live export, not a transactionally frozen snapshot. A complete record at the end distinguishes successful exports from interrupted downloads.
